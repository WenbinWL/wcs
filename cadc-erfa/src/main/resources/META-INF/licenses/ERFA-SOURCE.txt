The bundled Linux shared libraries are unmodified binaries from the Fedora 42
erfa-2.0.1-5.fc42 packages for aarch64 and x86_64.

The bundled macOS arm64 shared library is from the Homebrew erfa 2.0.1
arm64_sequoia bottle. Its install name was changed to use @loader_path and the
result was ad-hoc signed so it can be loaded alongside the JNI library.

Upstream source: https://github.com/liberfa/erfa
Fedora package: https://packages.fedoraproject.org/pkgs/erfa/erfa/
Homebrew formula: https://formulae.brew.sh/formula/erfa
